# Rewild

Stylized 3D restoration survival game prototype, powered by Babylon.js, TypeScript and Vite.

## Quick start

Requires Node.js 20.19+ or 22.12+.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite. Run `npm run build` to type-check and bundle.

Phase 1 provides a small explorable scene, basic lighting and a resize-aware render loop. Player movement, inventory and building are later milestones.
