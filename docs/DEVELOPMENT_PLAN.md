# Development Plan

1. Foundation: Vite, TypeScript, Babylon.js, rendered meadow, camera, docs and CI.
2. Player: third-person controller and movement.
3. World: terrain, vegetation and explorable landmarks.
4. Interaction and resources.
5. Inventory and survival.
6. Construction and restoration.
7. Living world and optimization.

Every phase must build cleanly and remain playable.
